# Архитектура 0.2

`core` содержит libGDX-приложение, модели и ресурсы; `lwjgl3` — Java 21 desktop launcher. Серверов и сетевых вызовов в игре нет.

- `Content` / `world.json`: карты, геометрия, двери, объекты, NPC и старые диалоги.
- `LifeContent` / `life.json`: девушки, темы, предпочтения, истории, товары, заказы и тестовые случаи.
- `GameState`: сохраняемые потребности, деньги, календарь, координаты, инвентарь, отношения, текущий код и история платежей.
- `World`: шаг 1/60 с, нормализация движения, коллизии по осям, переходы, актёры и валидация состояния.
- `Navigation`: актуальная цель; BFS по дверям и сетке коллизий с запасом для безопасного маршрута.
- `Life`: игровое время, потребности, еда, покупки, сон и подработка.
- `Economy`: списания, доходы, недельная аренда, задолженность и журнал операций.
- `Social`: знакомства, дневные ограничения, подарки, встречи, личные истории, пара, расставание и взаимное согласие.
- `Coding`: выбор алгоритма, исходник, набор, отладка, проверка, предпросмотр, идемпотентная оплата.
- `ByteScript`: ограниченные lexer/parser/AST/evaluator; выражения, сравнения и тернарный оператор; лимиты 4096 символов, 512 токенов, 48 уровней вложенности. Без системного eval.
- `LifeScreens`: интерфейсы обучения, магазинов, кодинга, знакомств, свиданий, контактов, сна, бюджета, карты и карманов.
- `CtrlLife`: ввод, режимы, камера, HUD, основной render loop, интеграция и сохранение.
- `SaveStore`: схема v2, миграция v1, валидация, временный файл и атомарная замена с fallback, исправная резервная копия. Неизвестные будущие версии отклоняются.
- `PixelCanvas`: SpriteBatch и FBO 480×270, nearest filtering, целочисленный масштаб, обратное преобразование координат мыши; предзагрузка и освобождение ресурсов.
- `AudioScene`: музыка, дождь, SFX, громкости и мягкий отказ без устройства.

Время физического движения и игрового календаря разделено. Диалог останавливает прогулку; доменные действия добавляют явное количество игровых минут. Смена режима сбрасывает удерживаемые клавиши. Поздняя сцена не выполняет мутацию отношений до подтверждённого перехода к утру.

Логические тесты работают без OpenGL. `ChapterSmoke` находится только в отдельном smoke source set и не входит в production JAR. Его первая цепочка использует InputProcessor и ходьбу; поздняя сцена проверяется на помеченной fixture. Производственная сборка ресурсов воспроизводима Python-генераторами.
