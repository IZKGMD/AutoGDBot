# VitaTextBridge / VitaControl Android 2.1

Нативное Android-приложение (Java, Android 8.0+) для LinuxOnVita с IceWM и Alpine chroot на PS Vita. Основной экран совместим с 1.2; новый раздел VitaControl открывается кнопкой.

## Важно об окружении

SSH подключается к **базовой LinuxOnVita-системе**, а пакеты находятся в Alpine-контейнере. Все команды магазина выполняются через `alpine-chroot -c '...'`, не напрямую через `apk` на хосте. Экран X11 работает на `DISPLAY=:0` в Alpine.

## Возможности VitaControl

- Магазин ARMv7-пакетов с поиском через `apk search`, каталогом популярных программ и подтверждением установки. Пакеты устанавливаются через `alpine-chroot -c`.
- Раздел экрана: снимок через `scrot` (нужен пакет), касание экрана пересчитывается в координаты X11 и отправляется через `xdotool`. Нажатия Esc/Enter/Tab/Alt+Tab, стрелки, клики и прокрутка. Снимки по запросу: **не потоковое видео**.
- Раздел YouTube Lite: установка `mpv` и `yt-dlp`, запуск ссылок YouTube при 240p. **Экспериментальная функция**: программное декодирование на Vita может тормозить, отсутствовать звук, а изменение YouTube/потоков может мешать запуску. Альтернатива — открыть YouTube в Badwolf, воспроизведение в браузере не гарантируется.
- Эффекты: Matrix (`cmatrix` в Sakura), `xeyes`, цифровые неоновые часы (`xclock`), `btop` в Sakura, установка компонентов с подтверждением.
- Статус Wi-Fi, памяти, загрузки, Alpine, списка пакетов; вывод действий.
- Старые функции SSH-команд и вставки текста в Sakura оставлены без изменений.

## Настройка

1. Подключи Vita и телефон к одному Wi-Fi. На главном экране укажи IP (ранее `192.168.1.141`), пользователя root и порт 22.
2. Открой **Vita Control 2.0**.
3. В разделе **Пакеты** установи `scrot` и `xdotool`, затем в **Экран** нажми «Показать экран Виты» (рабочий стол должен быть запущен через `alpine-desktop`).
4. Для YouTube установи `mpv` и `yt-dlp` и начни с короткого ролика. Если не запускается, лог на Vita: `/tmp/vita-control-youtube.log` внутри Alpine.

## Ограничения и безопасность

- Сеть и SSH должны работать; ключи сервера проверяются. Пароль не сохраняется на диск, SSH-ключ хранится приватно.
- Действия установки требуют явного подтверждения, имена пакетов валидируются, URL видеоролика принимается только по HTTPS с YouTube-доменов.
- Скриншот передаётся как Base64 JPEG ограниченного размера. Большие/сложные изображения могут не помещаться в буфер; пока это предварительный режим управления, не VNC.
- Установка пакетов может занять память и дисковое пространство Alpine; не запускай сразу много тяжёлых приложений.
- Не открывай SSH и VNC из этой системы в публичный Интернет.
- Реальная проверка видео, экрана и пакетов должна быть выполнена на самой Вите; GitHub Actions проверяет компиляцию, но не железо.

## Сборка

Gradle 8.9, JDK 17, Android SDK 35. `gradle :app:assembleDebug`.

## 2.1: быстрый перезапуск

В разделе **Система** доступна кнопка «Быстрая перезагрузка PS Vita» с отдельным подтверждением. Команда LinuxOnVita `reboot` возвращает консоль в Sony VitaOS, а не в сеанс IceWM.

Тестовые игры доступны отдельным архивом VitaGameLab: два прототипа — Pygame/SDL2 и Tkinter/Canvas, плюс Pygame Aurora и экспериментальный Panda3D пример (в Vita не проверен).
