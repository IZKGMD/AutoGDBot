# VitaTextBridge Android 1.0

Нативное Android-приложение (Java, Android 8.0+) для Alpine Linux с IceWM/Sakura на PS Vita. Не WebView.

## Функции

- SSH по Wi-Fi с паролем; проверка ключа хоста и подтверждение при первом подключении.
- Тест подключения (`uname -a && whoami`).
- Удалённое выполнение команд и вывод stdout/stderr/кода завершения.
- Вставка длинного UTF-8 текста в активное окно Sakura через X11 clipboard (`xclip` + `xdotool`).
- Сохраняет только хост/IP, имя пользователя и порт. Пароль не сохраняется.

## Подготовка PS Vita (в терминале Alpine Linux)

```sh
apk add openssh xclip xdotool
rc-service sshd start
rc-update add sshd default
```

Для SSH нужен пароль выбранного пользователя, например задайте его на Вите с помощью `passwd` (не вводите пароль в общий чат). Телефон и Vita должны быть в одной Wi-Fi сети. Перед вставкой текста сфокусируйте окно Sakura. По умолчанию X11 использует `DISPLAY=:0`.

## Android

1. Включите Wi-Fi, откройте APK, укажите IP (раньше у Vita был `192.168.1.141`), порт 22, имя пользователя и пароль Alpine.
2. Нажмите **Проверить SSH** и при первом подключении проверьте/подтвердите отпечаток ключа Vita.
3. Для команд используйте **Выполнить команду**.
4. Чтобы напечатать текст в Sakura, вставьте его в большое поле, убедитесь что окно Sakura активно на Vita, затем нажмите **Отправить текст на Виту**.

Если вставка не работает, проверьте наличие `xclip`, `xdotool`, значение `DISPLAY` и права пользователя на X11-сессию. Большой текст вставляется через clipboard; содержимое не интерпретируется оболочкой телефона как команда.

## Сборка

Нужен JDK 17, Android SDK 35, Gradle 8.9, доступ к Google Maven и Maven Central.

```sh
gradle :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. При сборке через GitHub Actions архив APK появляется в артефактах workflow.

## Безопасность и ограничения

- SSH пароль живёт в оперативной памяти приложения в течение работы и не записывается на диск.
- SSH known_hosts хранится в приватном каталоге приложения. Изменившиеся ключи не подтверждаются автоматически.
- Передача текста подразумевает работающую X11-сессию и активное окно Sakura; консольный режим tty сюда не входит.
- Это приложение для вашего собственного устройства в доверенной локальной сети. Не открывайте SSH-порт наружу без необходимости.
