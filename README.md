# CTRL+LIFE · Нулевой билд

**0.1.0 — Gate 0–1: «Первый вечер».** Настоящая настольная игра на Java 21 + libGDX / LWJGL3. Интерфейс на русском. Игра работает локально, без сети, аккаунтов и API.

Это первая игровая глава разработки, а не законченная демоверсия из полного задания. Здесь можно исследовать комнату, подъезд и улицу, знакомиться с соседями и вернуть Мире потерянное письмо. Компьютер пока можно осмотреть. ByteOS, KeyCode, покупки, ремонт, потребности и сон **ещё не реализованы**. Закрытые магазины не имеют неработающих интерфейсов.

## Быстрый запуск на Windows 10/11 x64

1. Извлеките **весь** архив `CTRL-LIFE-0.1.0-Windows-x64.zip` в обычную папку.
2. Дважды щёлкните `run.bat`.
3. Выберите «Новая игра». Введите имя (Backspace стирает), выберите куртку и начните вечер.

В Windows-архив включён Eclipse Temurin **Java Runtime 21.0.13+9 x64**. Устанавливать Java и подключаться к интернету для игры не нужно. Нужен видеодрайвер с OpenGL 2.0 или выше. Это переносимая сборка, **не установщик jpackage**. Windows-запуск не проверялся в текущей Linux-среде; смотрите `docs/WINDOWS_CHECKLIST.md` в исходниках.

В обычном Gradle-дистрибутиве без `runtime/` нужна установленная Java 21 x64. Для сборки исходников нужен **JDK 21**, содержащий `javac`, а не только JRE.

## Первые пять минут

Подойдите к компьютеру слева, нажмите **E**. Выйдите через дверь внизу комнаты. Познакомьтесь с Мирой в подъезде. Выход на улицу — внизу. Аркадий гуляет справа от дома, рядом с мастерской. Письмо лежит под лавкой около магазина, ещё дальше вправо. Верните его Мире и загляните домой.

Объекты реагируют только вблизи. Внизу экрана появляется действие. У NPC нет жёстких столкновений с игроком: они не перекрывают узкие проходы.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | Ходить |
| E / Enter | Взаимодействовать |
| ↑ / ↓, Enter | Выбрать пункт меню или реплику |
| 1–3 | Выбрать ответ в диалоге |
| Мышь | Нажимать кнопки меню |
| J | Журнал и текущая цель |
| I | Содержимое карманов |
| M | Схема улицы |
| Tab, удерживать | Текущая цель, если рядом нет действия |
| Esc | Назад / пауза |
| F5 | Сохранить |
| F11 | Полный экран / окно |

Клавиши ходьбы, взаимодействия и журнала переназначаются в настройках. Стрелки, Enter и системные горячие клавиши остаются доступными. Диалоги и меню останавливают игровое время. Потеря фокуса ставит прогулку на паузу и сбрасывает удерживаемые клавиши. В маленьком окне изображение остаётся чётким: логическое разрешение 480×270 увеличивается целым множителем.

## Сохранения

Один слот, автосохранение при переходах, выборе реплик и открытии паузы; вручную — F5. Новая игра требует подтверждения, если слот уже есть.

- Windows: `%LOCALAPPDATA%\CtrlLife\`
- Linux: `$XDG_DATA_HOME/CtrlLife/` либо `~/.local/share/CtrlLife/`
- `save.json` — основной слот; `save.backup.json` — предыдущая исправная версия.
- `settings.json` — настройки отдельно от истории.

Запись идёт через временный файл с проверкой и атомарной заменой, если файловая система её поддерживает. При повреждении основного слота игра предлагает продолжить из резервной копии и сообщает об этом. Если обе копии повреждены, меню остаётся рабочим. Для тестов можно задать отдельный каталог: `-Dctrl.dataDir=...`.

## Сборка из исходников

Windows: `build.bat` — сборка и логические тесты; `run.bat` — сборка и запуск. Пути заключены в кавычки, скрипты используют UTF-8. Фактический запуск .bat из пути с кириллицей проверяется на Windows отдельно.

Linux / терминал с JDK 21:

```sh
./gradlew test :lwjgl3:distZip
./gradlew :lwjgl3:run
```

Первое разрешение Gradle и зависимостей требует интернета. Gradle Wrapper 8.14.3 имеет проверку SHA-256; зависимости фиксируются lock-файлами. После загрузки зависимостей возможна сборка с `--offline`.

Готовый обычный ZIP: `lwjgl3/build/distributions/ctrl-life-0.1.0.zip`. Он содержит библиотеки и launcher, но не Java Runtime. В Linux запуск: `bin/ctrl-life`.

Логические тесты не требуют OpenGL. Графический сценарий требует доступного дисплея:

```sh
./gradlew :lwjgl3:guiSmoke -PsoakSeconds=300
```

Для проверки при 30 FPS: `-Pfps=30`. Для загрузки звука: `-PnoAudio=false` (нужно аудиоустройство). Проверка закрытия настроек без создания сейва: `-PmenuOnly=true`.

Сценарий управляет игрой через обработчик клавиатуры libGDX, проходит историю с письмом, проверяет загрузку, фокус и размеры окна; снимки пишет в `lwjgl3/build/smoke/screenshots/`. Он использует отдельное сохранение в `lwjgl3/build/smoke/save/`. Это инструментальный графический тест, не ручная проверка клавиатурной раскладки ОС.

## Состав и дальнейшая работа

- `core/`: модели, карты и диалоги, визуализация, UI, звук, сохранения, тесты.
- `lwjgl3/`: desktop launcher и графический тест.
- `tools/make_assets.py`: воспроизводимые оригинальные PNG, кириллические bitmap-шрифты и WAV; Python + Pillow и установленные DejaVu нужны только для регенерации ресурсов. Генератор вызывает `polish_assets.py` и `make_soundscape.py`; в поставке все PNG/шрифты/WAV уже готовы.
- `tools/make_content.py`: исходные карты и диалоги; готовый `world.json` уже включён.
- `GAME_DESIGN.md`, `ARCHITECTURE.md`, `CHANGELOG.md`, `TODO/ROADMAP.md`, `docs/QA.md`.

Следующий этап — Gate 2: продукты, магазин, деньги, отдых, прачечная и доступная подработка с сохранением всего цикла. После этого — ремонт ПК, затем настоящий ByteScript и KeyCode.
