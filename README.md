# CTRL+LIFE · 0.2.0

[Скачать сборку и исходники](https://github.com/IZKGMD/AutoGDBot/tree/ctrl-life/downloads)

Настольная игра на Java 21 + libGDX: маленькая комната в общежитии, заработок программированием, еда, аренда и отношения. Русский интерфейс, локальная игра без аккаунтов и сети.

Герою 23 года. После закрытия фирмы он приезжает в Берёзовск на маршрутке со старым компьютером и 10 000 ₽. Вступление объясняет переезд, расходы и первые действия. На экране всегда есть текущая цель; золотые точки ведут к нужной двери или объекту.

## Windows

1. Распакуйте **весь** `CTRL-LIFE-0.2.0-Windows-x64.zip`.
2. Запустите `run.bat`.
3. Выберите «Новая игра», чтобы увидеть новое вступление.

В комплекте Windows x64 Java Runtime Temurin 21.0.13+9. Устанавливать Java отдельно не нужно. Требуется OpenGL 2.0. Это portable ZIP. Проверено в Linux с настоящим desktop backend; запуск на Windows пока не проверен.

## Что можно делать

- Исследовать семь связанных локаций: комнату, подъезд, улицу, «Ложку», кофейню «Плёнка», мастерскую и сквер.
- Выполнять три заказа в KeyCode: выбрать алгоритм, напечатать код, получить настоящую ошибку, исправить исходник, пройти тесты, проверить результат и получить деньги.
- Покупать и есть продукты, спать до 08:00, следить за здоровьем, сытостью и энергией, оплачивать аренду. Экран бюджета хранит доходы и расходы.
- Знакомиться с Мирой (25), Асей (24), Никой (27). У каждой свои темы, интересы, любимые подарки, места свиданий и личная история.
- Общаться, дарить подарки, назначать встречи, ходить на свидания, предлагать отношения или расставаться. В устойчивых отношениях доступен вечер вдвоём по взаимному согласию: затемнение и утро, без откровенной сцены.

## Первый день

Подойдите к компьютеру, нажмите **E**. Возьмите «Кассу для Ложки»: сумма равна цене × количеству. В исходнике есть опечатка `prce`; тесты объяснят ошибку, отладка позволит исправить её на `price`. После тестов откройте предпросмотр и отправьте работу клиенту.

Следуйте золотым точкам до «Ложки», купите суп у стойки и съешьте его в карманах **I**. Вернитесь к Мире в подъезд, поговорите и пригласите её в сквер. На встречу нужно действительно прийти; маршрут обновится после приглашения. Затем вернитесь к кровати и завершите день.

## Управление

| Клавиши | Действие |
|---|---|
| WASD / стрелки | Ходить |
| E / Enter | Действие рядом с объектом |
| Мышь или ↑/↓ + Enter | Кнопки и выбор реплик |
| J | План и выбор следующей цели |
| M | Карта текущей локации / всей улицы |
| I | Еда и подарки |
| R | Контакты и поиск персонажа |
| B | Бюджет, платежи и долг |
| Esc | Назад / пауза |
| F5 | Сохранить |
| F11 | Полный экран |

В редакторе любые буквы печатают исходник и не двигают героя; есть кнопка «Допечатать». Скорость реакции не важна. Меню и диалоги останавливают время. Ходьба, действие и журнал переназначаются в настройках. FBO 480×270 масштабируется целым множителем.

## Экономика

Старт: **10 000 ₽**, первые три ночи оплачены. Аренда — **3 000 ₽** в дни 4, 11, 18 и далее. Заказы: 650 ₽ / 90 мин, 950 ₽ / 120 мин, 800 ₽ / 105 мин; каждый доступен один раз в игровой день. Оплата после реальных тестов и предпросмотра, повторная сдача денег не даёт.

Суп 220 ₽ восстанавливает 48 сытости; сэндвич 160 ₽ — 32. За полные сутки расходуется около 94 сытости. Два супа стоят 440 ₽. Два заказа по 650 и 950 ₽ покрывают еду и среднюю аренду, оставляя около 731 ₽ в день на подарки и накопления. Один дешёвый заказ не покрывает постоянные расходы. Свидание в сквере бесплатно; кафе или забегаловка — 850 ₽ на двоих, с едой. Подарки стоят 180–650 ₽.

Если денег не хватает на аренду, остаток записывается в долг. У доски во дворе есть доставка за 240 ₽; при бюджете ниже 250 ₽ можно получить бесплатный суп раз в день. Смерти от голода и выселения в этой главе нет. Подробные параметры: `GAME_DESIGN.md`.

## Сохранения

Один слот и предыдущая исправная копия. Автосохранение при переходах и действиях; F5 вручную. Windows: `%LOCALAPPDATA%\CtrlLife`; Linux: `$XDG_DATA_HOME/CtrlLife` или `~/.local/share/CtrlLife`. Настройки хранятся отдельно. Схема v2, миграция v1 и восстановление из backup поддерживаются. Старая позиция в перестроенной комнате переносится в безопасное место.

## Сборка

Нужен **JDK 21**, для первого разрешения зависимостей — интернет.

```sh
./gradlew test :lwjgl3:distZip
./gradlew :lwjgl3:run
```

Windows: `build.bat` и `run.bat`. Обычный Gradle ZIP `lwjgl3/build/distributions/ctrl-life-0.2.0.zip` не содержит JRE. Версии зависимостей зафиксированы lock-файлами; после первой загрузки можно использовать `--offline`.

Графическая проверка требует дисплея:

```sh
./gradlew :lwjgl3:guiSmoke -Pfps=30 -PnoAudio=false -PsoakSeconds=180
./gradlew :lwjgl3:guiSmoke -PmenuOnly=true
```

Сценарий использует отдельный слот в `lwjgl3/build/smoke/save`, снимки — `lwjgl3/build/smoke/screenshots`. Первую игровую цепочку проходит через обработчик ввода без телепортации. Проверка поздней сцены отношений использует явно обозначенное подготовленное состояние; достижимость отношений с каждой девушкой проверяется отдельно моделями.

Ресурсы уже включены. Для регенерации: Python + Pillow, DejaVu; `python tools/make_content.py` и `python tools/make_assets.py`. Код, контент, генераторы и лицензии входят в исходники.

## Границы версии

Это небольшая игровая глава с рабочим циклом, а не завершённый многолетний симулятор. Три повторяемых заказа; у каждой девушки одна открываемая личная история. Рабочих расписаний NPC, семейной жизни, апгрейдов жилья, ремонта компонентов и полноценного рабочего стола ByteOS пока нет. Набор декора и анимаций ограничен. Дождливое оформление пока не меняется по времени суток.
