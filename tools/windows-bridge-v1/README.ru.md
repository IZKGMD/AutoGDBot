# AutoGDBot Windows Bridge v1

Это помощник для удалённой проверки Geometry Dash на твоём Windows-компьютере из этого чата. Он не требует входа в OpenAI или установки Codex. Для связи используется твой приватный репозиторий `IZKGMD/AutoGDBot`, ветка `remote/windows-bridge-v1`.

## Запуск

1. Распакуй весь ZIP в обычную папку. Не запускай файлы внутри архива.
2. Создай fine-grained токен GitHub: <https://github.com/settings/personal-access-tokens/new?name=AutoGDBot-Bridge&target_name=IZKGMD&expires_in=1&contents=write>. Выбери **Only select repositories → AutoGDBot**, затем **Repository permissions → Contents → Read and write**. Проверь, что срок действия короткий. GitHub может запросить обычное подтверждение входа в свой аккаунт.
3. Открой `START.cmd`. Выбери свой `GeometryDash.exe`, вставь токен в скрытое поле терминала и нажми Enter. Node.js 18+ нужен; если ты уже установил Node.js для Codex, дополнительный npm install не требуется.
4. Дождись строки **CONNECTED**, оставь окно открытым и напиши в этот чат: **«мост запущен»**. Перед первой командой помощник прочитает статус новой сессии.

Токен не отправляй в чат. Он не записывается в конфигурацию и не передаётся помощнику в этом чате. Он используется локальным процессом для HTTPS-запросов к GitHub. Путь игры хранится только в локальном `config.json`.

## Что доступно после подключения

- Запустить или штатно закрыть выбранную Geometry Dash, вывести её окно вперёд.
- Получить снимок видимой клиентской области игры; нажать внутри неё или послать SPACE, ENTER, ESC, R, TAB, стрелки. Ввод и захват отклоняются, если другое приложение находится на переднем плане.
- Собрать последние строки только `timing-v*.csv` AutoGDBot. В настройках мода включи **Save timing CSV**. Geode 5.10.1 сохраняет их в `%LOCALAPPDATA%\GeometryDash\geode\mods\autogdbot.realtime`.
- При закрытой игре заменить пакет только с ID `autogdbot.realtime`, для GD 2.2081 и Windows x64. Предыдущие копии этого мода переносятся в `local-state/backups`; другие моды остаются на месте. В канале сейчас подготовлен существующий пакет v0.22.0, его установка не запускается сама.

## Остановка и ограничения

**F8** останавливает дальнейшее управление, в том числе при активном окне игры. Также можно закрыть консоль, нажать Ctrl+C в ней или создать рядом со скриптами файл `STOP.txt`. Чтобы снова запустить мост, убери `STOP.txt`. Сессия ограничена 60 минутами; новый запуск создаёт новый идентификатор, старые команды не выполняются.

Помощник не устанавливается в автозагрузку, не открывает входящих портов и не принимает произвольные команды PowerShell. Снимки и CSV попадают в приватную ветку GitHub и остаются в её истории. Запросы команд выполняются примерно раз в три секунды. Это канал для тестирования и обновлений: точные нажатия при прохождении уровня выполняет сам мод внутри игры. Мост не уменьшает лаги мода и не доказывает, что бот пройдёт Fingerdash.

Для снимков удобно оконное изображение игры, полностью видимое на мониторе. Игра и помощник должны работать от одного обычного пользователя Windows. Не запускай их с разными уровнями прав. Ограничения фокуса Windows, полноэкранного захвата и защиты приложения могут приводить к отказу действия; скрипт сообщает об этом и не повторяет нажатие.

## Что проверено

Проверены HTTP-обмен с тестовым сервером, повторные/просроченные команды, сохранение результатов при обрыве сети, ограничения ввода, PowerShell-синтаксис, компиляция C# и размер Win32 INPUT для x64. Установщик проверен на реальных временных файлах: другой ID/архитектура отклоняются, открытая игра блокирует установку, резервные копии сохраняются. Реальные Win32-нажатия, F8, снимки Geometry Dash и связь с твоим ПК ещё не проверены на Windows.

Исходники находятся в ветке <https://github.com/IZKGMD/AutoGDBot/tree/remote/windows-bridge-v1/tools/windows-bridge-v1>. Способ передачи файлов и необходимые права описаны в официальных документах GitHub: <https://docs.github.com/en/rest/repos/contents> и <https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens>.
