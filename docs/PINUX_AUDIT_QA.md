# Pinux Astra 0.5.1 — аудит и проверка

Основа: актуальная ветка `ctrl-life`, коммит пользователя `6f8e321`. Сохранены рабочий стол на Scene2D/VisUI, Astra Code и авторская подсветка ByteScript. Дата: 2026-11-04.

## Исправления

- Нативные окна ограничиваются рабочей областью при открытии, изменении размера, максимизации и смене разрешения. Верхняя панель и док остаются доступны.
- Текст приложений использует отдельные шрифты от масштабируемых панелей: на маленьком экране он не уменьшается вместе с ними. Подписи в Files/TaskMail ограничены доступной шириной.
- Настройки показывают текущее состояние на русском языке; тёплая тема действительно меняет фон, уменьшение анимаций отключает появление/закрытие окон и рабочего стола.
- Сессия сохраняет настройки и нормализованные позиции/размеры окон, включая восстановленную геометрию максимизированного окна. F5, выход из ПК и автосохранение в ОС сохраняют расположение. Схема v5 принимает прежние v1–v4.
- Терминал возвращает фокус при переключении окон, ↑/↓ работают с историей. Горячие клавиши оболочки обрабатываются до поля ввода. Ctrl/Alt-комбинации не вызывают случайный набор ByteScript.
- Свёрнутое приложение сохраняет индикатор дока. Закрывающееся окно сразу перестаёт считаться активным.
- TaskMail обновляет предложения при открытии. Files показывает реальный активный проект и количество версий; при отсутствии проекта не изображает существующий исходник.

## Проверки

78 тестов: без ошибок и пропусков. Включены пять новых проверок геометрии на разных экранах, экстремального перетаскивания, сохранения настроек/расположения, загрузки v4 и отклонения некорректных координат.

Расширенный `PinuxSmoke` начинает настоящую отдельную игровую сессию. Проходит лаунчер/поиск, выбор заказа, набор, ошибку и исправление, настоящие тесты ByteScript, предпросмотр, лабораторию и версии. Проверяет изоляцию ввода лаунчера, терминал, перетаскивание/размер окна, историю команд, настройки, F5, чтение сохранённого состояния и повторный вход в ПК. В 960×540, 1280×800 и 1920×1080 проверяет все открытые окна на выход за экран. На основном этапе окно 1440×810.

Логи: `pinux-0.5.1-tests.log`, `pinux-0.5.1-gui.log`, `pinux-0.5.1-build.log`. Снимки: `screenshots/pinux-audit/`. Просмотрены Astra Code, несколько перекрывающихся окон, настройки при 960×540 и восстановленная сессия при 1920×1080.

## Пределы проверки и следующая работа

Среда Linux/Xvfb с настоящим desktop backend, Java 21, Gradle 8.14.3. Windows, системный DPI и физическое аудиоустройство не проверены. Это проверенный проход по конкретным сценариям, не гарантия отсутствия любого дефекта.

Files пока остаётся обзором активного проекта с переходом в IDE; произвольный файловый менеджер и восстановление списка открытых приложений ещё предстоят. Старый PixelCanvas `PinuxWindowManager` не управляет текущими VisWindow: его привязка к краям и двойное нажатие на заголовок ещё не перенесены в нативный слой.
