# Проверка 0.7.0

## Модель

102 логических теста. Проверка масштаба охватывает 16:9, 16:10, ультраширокий экран, границы изображения и обратное преобразование координат мыши. Новый `DateStoryTest` проверяет все 72 комбинации ответов девяти свиданий, однократную оплату и награду, нехватку денег/энергии, ранний уход, сохранение каждого ответа, невозможность продолжать встречу из другого места, переход через полночь, защиту прогресса от некорректного сейва, уменьшенную награду за повтор, общие планы, сроки и миграцию v6. Проверка достижимости трёх личных финалов переведена на новые свидания: обычные игровые действия и дни, без повышения показателей вручную.

## Реальная графика и ввод

`DateSmoke` запускает настоящий LWJGL3 backend и отправляет клики через игровой InputProcessor. **202 кадра**: все девять свиданий с выбором, ответом и итогом; страницы общения для трёх героинь в 960×540, 1280×800 и 1920×1080; контакты; возвращение к оплаченной встрече. Текст новых экранов измеряется перед отрисовкой: выход за отведённую высоту останавливает проверку. Полный набор кадров доступен в artifact релизного workflow.

Отдельно запускаются `RelationshipSmoke` (главы, занятия, журнал, перенос/отмена, сохранение), `VisualSmoke` (все семь карт днём/ночью, края камеры, перекрытие мебелью, памятные вещи и эффекты в границах сцен), `PinuxSmoke` и матрица Astra Code из 112 кадров. Новый интерфейс использует один маршрут отрисовки; прежняя копия социального интерфейса удалена.

Полноразмерные кадры и сводные листы просмотрены вручную после выполнения сценариев. Представительные изображения находятся в `docs/screenshots/close-to-home/`; логи — `docs/close-to-home-*.log`.

```sh
./gradlew test
./gradlew :lwjgl3:guiSmoke -Pdates=true
./gradlew :lwjgl3:guiSmoke -Prelationships=true
./gradlew :lwjgl3:guiSmoke -Pvisual=true
./gradlew :lwjgl3:guiSmoke -Ppinux=true
./gradlew :lwjgl3:guiSmoke -PlayoutAudit=true
```

Проверено в Linux/Xvfb. Упаковка Windows и наличие встроенной Java проверяются workflow; физический Windows, системный DPI, звук на реальном устройстве и многочасовая сессия здесь не проверялись. Портреты — отдельные иллюстрации персонажей; они не являются анимацией героинь или изображением текущего места свидания. Новые свидания — авторские сцены с выбором, не симулятор свободного диалога.
