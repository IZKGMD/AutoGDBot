# CTRL+LIFE 0.6.1 — исправление разметки Astra Code

Исправлен экран выбора реализации, показанный на пользовательском скриншоте, и общие причины наложений в остальных разделах IDE.

## Что было сломано

Кнопки разрешали перенос подписи, но их высота оставалась 30 пикселей, а ширина некоторых действий — около 160. Многострочные подписи выходили за кнопки. Шрифты приложений увеличивались с размером окна, тогда как высоты строк и отступы оставались постоянными. Минимальные размеры вложенных таблиц могли вытеснять нижнюю консоль и кнопку выхода. Полоса прогресса ошибочно требовала минимум 640 пикселей и после набора кода расширяла узкую рабочую область, вытесняя кнопки за правый край окна.

## Исправления

- Однострочные подписи кнопок, действия на доступную ширину, достаточная высота и интервалы.
- Убраны фиксированные 600/610 пикселей у поясняющего текста; описание задания выровнено по левому краю.
- Заголовок раздела разделён на строки: категория, название, пояснение.
- Нативный размер шрифта приложений сохраняется при изменении разрешения; моноширинные подписи используют ту же независимую группу шрифтов.
- Полоса прогресса рассчитывается от фактической ширины редактора, включая полностью набранный код и изменение размеров окна.
- В узком режиме убраны дублирующие элементы тулбара; тесты доступны в основном тулбаре, версии — в боковой навигации.
- Навигация прокручивается, «Выйти из ПК» закреплено снизу. Нижняя консоль подстраивается под высоту окна.
- Минимальная геометрия Astra Code — 800×360 в пределах экрана. Окно можно развернуть; длинные страницы в небольшом окне прокручиваются.

## Проверка результата

`AstraLayoutSmoke` формирует **112 реальных кадров**: 12 разделов и два дополнительных состояния редактора (ошибка компиляции / успешные тесты), четыре разрешения — 960×540, 1280×800, 1440×810, 1920×1080 — и два состояния окна: обычное и развёрнутое. При 960×540 обычное окно дополнительно проверяется на минимальном размере 800×360.

На каждом кадре автоматически проверяются ширина/высота отрисованного текста относительно выделенной области, подписи кнопок относительно их границ, выход непрокручиваемых элементов за окно и доступность закреплённой кнопки выхода. Проверка добавлена в GitHub workflow перед публикацией ZIP; полный набор PNG загружается как artifact workflow.

Вручную просмотрены сводные листы всех 12 разделов для восьми сочетаний размеров/режимов. Дополнительно просмотрены полноразмерные кадры исходного проблемного экрана 1920×1080, редактора с ошибкой, маленького окна после успешных тестов и лаборатории. Это отдельный визуальный проход, а не вывод из факта успешной компиляции.

[Лог проверки](https://github.com/IZKGMD/AutoGDBot/blob/ctrl-life/docs/astra-layout-0.6.1.log). [Полноразмерные кадры и сводные листы](https://github.com/IZKGMD/AutoGDBot/tree/ctrl-life/docs/screenshots/astra-layout). Изолированные состояния в матрице предназначены для проверки разметки; полноценная игровая цепочка отдельно проходит через `PinuxSmoke`. Регрессия отношений также проверяется отдельно. Логические тесты: 90 без ошибок/пропусков.

## Ограничения

Проверено в Linux/Xvfb с настоящим libGDX/LWJGL3 backend. Нативный Windows DPI и разные физические мониторы здесь не проверены. Узкие окна используют прокрутку; текст программ прокручивается горизонтально. Матрица проверяет авторские состояния и поддерживаемые размеры, а не гарантирует отсутствие любого дефекта при произвольном будущем контенте.

## Запуск

```sh
./gradlew test
./gradlew :lwjgl3:guiSmoke -PlayoutAudit=true
./gradlew :lwjgl3:guiSmoke -Ppinux=true
./gradlew :lwjgl3:guiSmoke -Prelationships=true
```

Архив Windows содержит Java. Распаковать целиком и запустить `run.bat`. Сохранения 0.6.0 поддерживаются.
