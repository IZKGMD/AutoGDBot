# Проверка графики 0.10.0

Локальная среда: Java 21, Linux, настоящий LWJGL3 backend, Xvfb 1920×1080, Mesa software OpenGL. Это исполнение игры с захватом кадров, а не HTML-макет или проверка одной компиляции.

- **121 тест, 0 ошибок и пропусков.** В том числе реальные PNG: читаемость, размер до 2048 px, прозрачные отступы каждой ячейки, отсутствие обрезки и попадания соседних предметов, непрозрачность девяти материалов. Шесть новых атласов проверены внутри установленного JAR.
- **55 кадров VisualSmoke.** Все семь карт днём и ночью; края камеры улицы; герой перед холодильником и за ним, перед деревом и за ним; распакованные коробки; SSD и кресло; подход вплотную к ПК; памятные вещи. Каждая карта дополнительно снята в 960×540, 1280×800 и 1920×1080. Уменьшение эффектов переключается через настоящий интерфейс настроек и проверяется в сохранённом файле.
- Шейдер обязан скомпилироваться. При захватах проверяется отсутствие ошибок OpenGL. Пиксели снаружи интерьерных срезов должны сохранять исходный цвет: новые материалы, свет и дождь не могут выходить за границы.
- **35 кадров ProductSmoke.** Новая игра, ввод и ходьба через InputProcessor, первый заказ, исправление и выплата 650 ₽, двери, забегаловка, покупка и употребление супа; далее отмеченные состояния страниц предметов, журнала, длинных сообщений и сохранений. Полное описание маршрута — [в проверке главы](FIRST_CHAPTER_QA.md).
- Диагностика готового дистрибутива: нативные библиотеки libGDX/LWJGL, данные, ByteScript, временные сохранения и пути с кириллицей. Пользовательские сохранения не используются.

Репрезентативные полноразмерные кадры просмотрены вручную. По результатам исправлены растяжение столика, подложка пруда, пересечение скамейки с ячейкой фонаря, положение кресла и указатель поверх головы героя. [Галерея](WARM_LIGHT_GALLERY.md) содержит кадры без ретуши.

Логи: [сборка, тесты и финальный графический проход](warm-light-final.log), [игровой маршрут](warm-light-product.log), [диагностика](warm-light-install.log), [JUnit и ресурсы дистрибутива](warm-light-assets.log).

```sh
./gradlew :core:test :lwjgl3:installDist :lwjgl3:guiSmoke -Pvisual=true
./gradlew :lwjgl3:guiSmoke -Pproduct=true
java -cp 'lwjgl3/build/install/ctrl-life/lib/*' life.ctrl.desktop.DesktopLauncher --check-install
```

Релизный workflow повторяет тесты, Pinux, отношения, свидания, графику, 137 кадров разметки Astra Code и маршрут нового игрока. Отдельное задание Windows скачивает ZIP, сверяет SHA256, распаковывает в путь «Проверка игры» и запускает встроенную Java через `run.bat --check-install`. Публикация разрешена только после успешного Windows-задания. Фактический статус и логи удалённой сборки находятся в [GitHub Actions](https://github.com/IZKGMD/AutoGDBot/actions/workflows/pinux-astra-release.yml).

Ограничения: программный OpenGL не заменяет проверку видеодрайверов, звука и DPI 125/150% на физических Windows-компьютерах. Запасной путь старого освещения предусмотрен при ошибке шейдера; старые GPU здесь не эмулировались. Анимационные листы персонажей в этом обновлении не перерисованы, что остаётся отдельным этапом согласования стиля окружения и персонажей.
