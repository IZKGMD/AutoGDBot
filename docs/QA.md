# Проверки 0.1.0

Дата: 2026-11-03. Среда: Linux x86_64, JDK 21.0.13+9, Gradle Wrapper 8.14.3, виртуальный дисплей Xvfb. Запускается настоящий LWJGL3/OpenGL desktop backend.

## Логика — 22 теста

`./gradlew test`: 22 passed, 0 failed, 0 skipped.

- Валидность ID карт, дверей, реплик и эффектов.
- Одинаковая скорость прямого и диагонального движения.
- Стены останавливают движение, нет туннелирования.
- Одинаковое число фиксированных шагов даёт одинаковое состояние.
- Все карты связаны двусторонними дверями, точки появления свободны.
- Каждый интерактивный объект достижим из точки входа, проверяется поиском по сетке коллизий.
- Маршруты NPC детерминированы и не пересекают препятствия.
- Письмо можно подобрать до просьбы; повторная сдача/подбор после завершения исключены.
- Контекст диалогов меняется после находки и возврата письма.
- Сейв сохраняет координаты, карту, имя с кириллицей, одежду, флаги и время.
- Сохранение работает на всех трёх картах.
- Повреждённый основной файл восстанавливается из backup; повреждение не затирает исправный backup.
- Будущая версия и некорректные координаты отвергаются без замены исправного слота.
- Настройки читаются обратно, повреждение даёт defaults; конфликты клавиш отклоняются.

Дополнительно проверяются реальные PNG всех карт и объектов, размеры спрайтов/портретов и визуальных вариантов, наличие русских глифов и размещение всех реплик в трёх строках рядом с портретом.

## Инструментальный графический проход

Пять минут при 60 FPS: полный маршрут и последующая работа приложения прошли без исключений. Повторный пятиминутный проход при 30 FPS с включённым OpenAL через null-устройство также прошёл; подробный результат сохранён в `docs/validation.log`. Загрузка всех звуковых ресурсов подтверждена до начала сценария.

Сценарий подаёт реальные события обработчику ввода libGDX, без прямого переноса координат персонажа:

1. Главное меню → создание → комната.
2. Подход к ПК, диалог, запись симптомов.
3. Подъезд, разговор с движущейся Мирой, принятие просьбы.
4. Улица, обход препятствий, путь до лавки, получение письма.
5. Карманы и карта; обратный маршрут в подъезд.
6. Передача письма, возврат домой и обновлённый журнал.
7. Потеря фокуса → пауза; проверка остановки времени.
8. Кнопка громкости мышью, переназначение W → T, возврат в игру и движение новой клавишей.
9. Выход в меню и «Продолжить»; флаги истории и карта сохранены.
10. Окна 960×540 и 1920×1080, возврат к 1440×810.
11. Продолжительная ходьба в комнате без пересечения препятствий.

После этих проходов дополнительно исправлена защита игрового слота: выход из настроек главного меню без начала игры не создаёт сохранение. Для этого есть отдельный `-PmenuOnly=true` сценарий.

Снимки меню, диалогов, улицы, журнала, настроек и малого окна просмотрены. После первого запуска исправлены BMFont padding и метрики глифов; после первого маршрута добавлен запас до препятствий в автоматический навигатор. Позднее графический сценарий вынесен в отдельный source set, чтобы обычный `test` не требовал GUI.

## Что не проверено

- Windows 10/11, .bat-скрипты и запуск из пути с кириллицей на Windows.
- Физическая русская раскладка ОС, Alt+Tab и F11 на реальном Windows-драйвере; тест фокуса вызывает callback приложения напрямую.
- Слышимость/баланс звука через колонки. Null-устройство подтверждает загрузку и работу API без реального аудиовыхода.
- Windows DPI 125/150%, несколько мониторов и длительные многочасовые сессии.
- jpackage/MSI/EXE installer не создавался. Подготовлен portable ZIP с официальным Temurin JRE для Windows.

## Ограничения версии

Это Gate 0–1, а не полная вертикальная демоверсия. Три карты, три NPC, одна небольшая история. Непрерывное дождливое оформление, часы без полноценной смены дня и ночи. NPC гуляют по маршрутам, но не имеют рабочих расписаний. Нет экономики, настоящего сна, стирки, ремонта, ByteOS, KeyCode, ByteScript, романтики и семейной системы. UI использует единое логическое разрешение: масштаб меняет весь кадр, отдельного размера шрифта нет.

Следующий этап — Gate 2 с тестируемым бытовым циклом и миграцией сейва v1 → v2. Ручная проверка Windows: `WINDOWS_CHECKLIST.md`.

## Проход после обновления ассетов

Полный сценарий дополнен поливом растения, разбором коробки и сменой куртки; после продолжения проверяется сохранность этих изменений. Портретные диалоги и новые сцены просмотрены на снимках реального кадра игры. Финальная квалификация после обновления текстур и музыки — `quality-validation.log`; отдельная проверка главного меню — `menu-validation.log`.

В `audio-analysis.txt` записаны пик и RMS каждого WAV, а также разность крайних отсчётов. Клиппинга нет. Эти измерения не заменяют прослушивание на реальных колонках.

Регенерация через `tools/make_assets.py` повторно выполнена: все 48 готовых ресурсов побайтово совпали. Контроль текстур включает не только исходные спрайты, но и изменяемые варианты объектов и портреты.

Обычный launcher из `installDist` отдельно запущен в Linux с новой иконкой окна и включённым OpenAL. Окно 1440×810 создано, запрос обычного закрытия обработан, процесс завершился с кодом 0; ошибок в консоли нет. Закрытие без начала игры не создало игровой слот.
