# Проверки CTRL+LIFE 0.2.0

Среда: Linux x86_64, Java 21.0.13+9, Gradle 8.14.3, настоящий LWJGL3/OpenGL backend в Xvfb. Дата: 2026-11-03.

## Логика

45 тестов: 0 ошибок, 0 пропусков. Проверяются карты и достижимость объектов, движение и коллизии, PNG/шрифты, сохранения и резервная копия, миграция v1, потребности, покупки, аренда, долг, помощь при нулевом бюджете, ByteScript, ремонт каждого варианта алгоритма, однократная оплата, защита от подмены заказа, дневные ограничения отношений, физическое место свидания и явное согласие.

Экономический сценарий на 14 дней: два заказа и два супа ежедневно, сон до 08:00, аренда в дни 4 и 11; итог 20 240 ₽, без долга и голодания. Для каждой девушки отдельно проверена достижимая последовательность четырёх дней: разговоры → свидания → пара → вечер вдвоём; отказ не увеличивает счётчик близости.

## Графический сценарий

Проход при 30 FPS с обновлёнными ресурсами выдержал 180 секунд: `chapter-0.2-validation.log`. Финальный проход при 60 FPS после исправлений взаимодействия и повторного входа в ПК записан в `chapter-0.2-release.log`. Отдельная проверка главного меню — `chapter-0.2-menu.log`; настройки до начала игры не создают игровой слот.

Сценарий подаёт события клавиатуры и мыши в игровой InputProcessor. Первую цепочку проходит ходьбой без переноса координат: вступление → ПК → выбор алгоритма → печать без движения героя → ошибка компилятора → реальная правка → тесты → интерактивный предпросмотр → оплата 650 ₽ → путь до забегаловки → покупка и еда → разговор с Мирой → приглашение → путь в сквер → свидание → карта → домой → сон → бюджет → выход и продолжение. Дополнительно проверяется остановка времени в паузе.

Поздняя сцена отношений проверяется на отдельно помеченном подготовленном состоянии: приглашение → явное согласие → затемнение → утро → сохранённое воспоминание. Этот фрагмент не выдаётся за ручное прохождение четырёх дней. Проверены окна 960×540 и 1920×1080, контакты и портреты.

Снимки реальных кадров просмотрены: обучение, исходник и тесты, комната, улица, выбор свидания, бюджет, карта, контакты. Исправлены угловые проходы маршрутизатора и перехват действия у дверей проходящим NPC. Повторный вход в ПК после выхода до выбора алгоритма возвращает доску заказов; это включено в графический проход. Автоматическое управление учитывает длину шага при 30 FPS. Для снимков выдерживается завершение переходов и обновление UI.

## Ресурсы и поставка

Повторная генерация всех 61 файлов ресурсов дала побайтовое совпадение. Контрольные суммы: `resource-sha256.txt`. Windows portable содержит официальный Temurin JRE с лицензиями. Сборщик проверяет целостность ZIP и совпадение каждого ресурса внутри core JAR с исходным файлом. Исходный архив исключает build, кеши, сохранения и downloads.

## Не проверено

Windows 10/11, фактический запуск BAT, Windows DPI, кириллица в пути, раскладка ОС, физическое аудиоустройство и многочасовые игровые сессии. OpenAL с null-устройством подтверждает работу API и загрузку, но не слышимый баланс звука. Для Windows есть отдельный ручной checklist. MSI/EXE-установщика нет.

## Ограничения содержания

Семь карт, три повторяемых заказа, три романтических персонажа с одной открываемой историей у каждой. Нет расписаний NPC, семейного быта, апгрейдов жилья, полноценного рабочего стола и свободного редактора исходников. Дождливое оформление не меняется с часами. Старые результаты 0.1 сохраняются отдельно в `archive-0.1/` и не описывают проверку новой версии.
