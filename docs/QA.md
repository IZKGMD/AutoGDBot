# Проверки CTRL+LIFE 0.4.0

Среда: Linux x86_64, Java 21.0.13+9, Gradle 8.14.3, LWJGL3/OpenGL в Xvfb. Дата: 2026-11-04.

## Логика и ресурсы

67 тестов, без ошибок и пропусков. Сохранены проверки движения, достижимости объектов, экономики, ByteScript, карьеры, отношений и сохранений. Новые проверки:

- Двойная плотность текстур всех карт и физических объектов соответствует прежним игровым размерам.
- Каждый из 16 кадров каждого персонажа имеет прозрачные внешние края: соседний кадр не попадает в текущий.
- Свет и тени полностью прозрачны по краям текстур, без прямоугольной рамки.
- Пиксели вне границ комнат остаются непрозрачным фоном, без декора.
- Атласы шрифтов не превышают 2048×2048, все символы находятся внутри атласа; кириллица сохранена.
- Сохранение v3 с героем внутри добавленного холодильника переносит его ко входу, сохраняя деньги, опыт, выпущенные проекты и улучшения. После записи v4 загрузка сохраняет те же значения.

## Графическая проверка

`chapter-0.4-visual.log`: отдельные явно подготовленные состояния всех семи локаций, дневное и ночное освещение. Края камеры на улице, улучшенное рабочее место, карта с мебелью, герой перед холодильником и за ним. Пиксели в пустом пространстве за комнатами проверяются автоматически: свет и погода не меняют их цвет. Состояния перед снимками проходят валидацию коллизий.

Окна 960×540, 1440×810, 1920×1080 и 1280×800 с полями вокруг кадра. Просмотрены реальные кадры комнаты, улицы, кафе, забегаловки, мастерской, подъезда, сквера, перекрытия холодильником и интерфейса. Шрифт рисуется в плотности окна, подписи ограничиваются своими областями. Снимки в `screenshots/visual/`.

`chapter-0.4-workbench.log`: полный сценарий профилировщика, своих тестов, коммита и отката, оплаты, улучшений, трёх этапов бота, портфолио и сохранения; действия через InputProcessor на явно обозначенном подготовленном состоянии карьеры.

`chapter-0.4-validation.log`: первый день при 30 FPS, не менее 180 секунд. Вступление → реальная ходьба → ПК → ошибочный код → исправление → тесты и предпросмотр → оплата → забегаловка и еда → приглашение Миры → путь в сквер и свидание → домой → сон → бюджет → сохранение и продолжение. Поздняя сцена отношений использует отдельно обозначенное подготовленное состояние. Проверяются пауза и размеры окна.

`chapter-0.4-menu.log`: настройки главного меню не создают игровой слот.

## Воспроизводимость и поставка

119 генерируемых файлов пересозданы в отдельном каталоге и побайтово совпали. Манифест `resource-sha256.txt` содержит 120 ресурсов, включая лицензию шрифта. Архив Windows включает Temurin JRE и лицензии. Проверяется целостность ZIP и совпадение всех ресурсов внутри core JAR с исходными файлами. Исходный архив исключает сборки, кеши, .git и downloads.

## Практические границы проверки

Windows 10/11, Windows DPI и раскладки, запуск BAT и реальное аудиоустройство здесь не проверялись. OpenAL с null-устройством подтверждает загрузку и вызовы API, но не слышимый звук. Нет проверки многочасовых сессий и всех моделей GPU. Матрица кадров и автоматические проверки снижают риск визуальных ошибок, но не являются гарантией отсутствия любого дефекта на любом устройстве.

Графика остаётся стилизованной 2D. Нет 3D, физически точных теней и произвольного масштабирования интерфейса; целочисленная сетка сохраняет поля при другом соотношении сторон. Предыдущие результаты находятся в `archive-0.1/`, `archive-0.2/`, `archive-0.3/`.
