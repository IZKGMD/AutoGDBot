# Ручная проверка Windows 10/11 x64

В текущей среде эти проверки **не выполнялись**. Архив содержит Java Runtime для Windows, но графическая проверка проведена в Linux/Xvfb/Mesa.

- [ ] Извлечь весь ZIP в папку `C:\Игры\CTRL LIFE\`, содержащую пробелы и кириллицу.
- [ ] Запустить `run.bat` без установленной Java; должен использоваться `runtime\bin\java.exe`.
- [ ] В исходниках проверить понятную ошибку без Java и без JDK, затем `build.bat` с JDK 21.
- [ ] Новая игра; имя по-русски, Backspace, выбор куртки, мышь и клавиатура.
- [ ] Проверить чёткий текст и спрайты при 960×540, 1440×810 и 1920×1080; Windows scaling 100/125/150%.
- [ ] F11 туда и обратно; Alt+Tab, потеря фокуса, отсутствие залипания ходьбы.
- [ ] WASD в английской и русской раскладке ОС; стрелки как резерв. Проверить переназначение.
- [ ] Обойти комнату, подъезд и улицу: нет прохода через мебель/фасады и за края карты.
- [ ] Взаимодействовать с каждым доступным объектом. Мира, Аркадий, Лев; повторные разговоры.
- [ ] Подобрать письмо до разговора с Мирой; отдать один раз; вернуться домой.
- [ ] F5, выход, продолжение; убедиться, что письмо и флаги сохраняются.
- [ ] При закрытой игре повредить копию save.json, проверить восстановление из save.backup.json. Сначала отдельно скопировать оригиналы.
- [ ] Проверить слышимость шагов, кликов, дождя и музыки на реальном аудиоустройстве. Регуляторы и нулевая громкость.
- [ ] Поиграть не менее 15 минут; убедиться в стабильной производительности и отсутствии заметных утечек.

Сбой запуска: сохранить текст консоли и указать Windows, GPU/драйвер, размер окна и действие, после которого произошла ошибка. Сохранения: `%LOCALAPPDATA%\CtrlLife\`.
