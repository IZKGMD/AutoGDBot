# Проверки CTRL+LIFE 0.3.0

Среда: Linux x86_64, Java 21.0.13+9, Gradle 8.14.3, настоящий LWJGL3/OpenGL backend в Xvfb. Дата: 2026-11-04.

## Логика

61 тест: 0 ошибок, 0 пропусков. К предыдущим проверкам движения, карт, экономики, потребностей, отношений и сохранений добавлены проверки карьеры: реальное число операций и выполненной ветви, отказ в сдаче медленной программы, точный откат исходника, сброс предпросмотра после отката, сохранение версий, запрет премии за повторные/штатные тесты, дедлайн с учётом длительности работы, запрет подмены активного проекта, ранги и лимит трёх заказов, смена предложений, реальные эффекты улучшений, порядок этапов бота, недостаток средств на запуск, миграция v2, время суток и погода.

Отдельно проверены запуск бота через полночь без немедленного дохода и запрет сброса обещанного дедлайна через отказ/повторное принятие. Доход бота не повторяется после сохранения и загрузки. Все варианты алгоритмов всех 12 задач проходят через ремонт, настоящие тесты и оплату/списание.

Экономическая регрессия на 14 дней: два начальных заказа и два супа ежедневно, сон до 08:00, аренда в дни 4 и 11; итог 20 240 ₽, без долга и голодания. Для каждой девушки отдельно проверена достижимая последовательность четырёх дней: разговоры → свидания → пара → вечер вдвоём; отказ не увеличивает счётчик близости.

## Графические сценарии

`chapter-0.3-workbench.log`: подготовленное состояние середины карьеры; все последующие действия через настоящий InputProcessor. Биржа → медленная программа с верным ответом → отказ по лимиту операций → свои входные случаи → исправление → коммит → откат и отказ тестов → восстановление рабочего кода → сравнение 7 и 1 операции → предпросмотр → 1 550 ₽ с премией → SSD и кресло → все три этапа бота → сохранение → меню → продолжение → портфолио и отзыв. Дополнительно проверены дневной/вечерний кадры улицы и улучшенная комната. Этот сценарий использует явно обозначенные fixtures и не выдаётся за прохождение от первого дня.

`chapter-0.3-validation.log`: первый день при 30 FPS с аудио через null-устройство, сценарий длительностью не менее 180 секунд. Начало проходится ходьбой без переноса координат: вступление → ПК → алгоритм → набор → ошибка компилятора → патч → тесты → интерактивный предпросмотр → оплата → путь до забегаловки → покупка и еда → разговор с Мирой → приглашение → путь в сквер → свидание → карта → домой → сон → бюджет → выход и продолжение. Проверяются пауза, приоритет взаимодействий у объектов и повторный вход в ПК. Поздняя сцена отношений проверяется на отдельно помеченной fixture. Окна 960×540 и 1920×1080.

`chapter-0.3-menu.log`: настройки из главного меню не создают игровой слот. Дополнительный более ранний проход первого дня при 60 FPS: `chapter-0.3-firstday-60fps.log`.

Кадры лаборатории, истории версий, портфолио, своего проекта, комнаты и улицы просмотрены. Исправлены нечитабельные обозначения при ошибке компиляции и слишком тёмные отметины покрытия улицы. Оригинальные PNG в `screenshots/`.

## Ресурсы и поставка

65 генерируемых файлов ресурсов повторно созданы в отдельном каталоге: побайтовое совпадение. Манифест `resource-sha256.txt` содержит все 66 файлов, включая неизменённую лицензию шрифта. Windows portable содержит официальный Temurin JRE с лицензиями. Сборщик проверяет целостность ZIP и совпадение каждого ресурса внутри core JAR с исходным файлом. Исходный архив исключает build, кеши, сохранения и downloads.

## Не проверено

Windows 10/11, фактический запуск BAT, Windows DPI, кириллица в пути, раскладка ОС, физическое аудиоустройство и многочасовые игровые сессии. OpenAL с null-устройством подтверждает работу API и загрузку, но не слышимый баланс звука. Для Windows есть отдельный ручной checklist. MSI/EXE-установщика нет.

## Ограничения содержания

Семь карт, 12 авторских задач (9 повторяемых клиентских и 3 этапа собственного проекта), три романтических персонажа с одной открываемой историей у каждой. Нет расписаний NPC, семейного быта, переезда, полноценного рабочего стола и свободного редактора исходников. Профилировщик измеряет операции ByteScript, не физическую производительность CPU; история версий локальная, без настоящего Git. Освещение и погода работают, набор анимаций ограничен. Старые результаты находятся в `archive-0.1/` и `archive-0.2/`.
