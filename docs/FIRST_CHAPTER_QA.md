# Проверка 0.9.0

119 логических тестов. Новый сценарий завершает первую главу за восемь игровых дней обычными действиями: заказы, еда, первое свидание с каждой из трёх девушек в отдельных прохождениях, запуск бота, покупка оборудования и оплата аренды. Проверено сохранение завершения после последующих расходов, загрузка сейва v8 и приоритет потребностей перед встречей. Отдельно проверяется альтернативное условие личной истории.

`ProductSmoke` запускает настоящий LWJGL3 backend и отправляет ввод через InputProcessor. Начало — новая игра и вступление, затем ходьба к ПК, взаимодействие, принятие заказа, две фазы набора, тесты, выбор исправления, предпросмотр и выплата 650 ₽. Деньги и опыт для этой проверки не поднимаются вручную. После оплаты персонаж проходит через двери до «Ложки», покупает суп и съедает его через карманы.

Следующие этапы используют явно отмеченные состояния для инвентаря и завершённой главы: покупки и страницы карманов, четыре страницы прогресса в 960×540, 1280×800 и 1920×1080, длинное сообщение до последней страницы, итог главы, загрузка сохранения и новая игра после подтверждения замены: предыдущие цели и завершение в неё не переносятся; старая история находится в отдельном архиве. 35 снимков. Высота новых текстовых блоков проверяется перед рисованием. Представительные полноразмерные кадры просмотрены и лежат в `docs/screenshots/first-chapter/`.

Диагностика `--check-install` проверяется на собранном дистрибутиве, включая загрузку нативных библиотек libGDX и LWJGL без создания OpenGL-контекста. Релизный workflow дополнительно выполняет прежние проверки Pinux, отношений, свиданий, графики мира и разметки Astra Code. Публикация перенесена после отдельного задания Windows: оно скачивает готовый ZIP, сверяет SHA256, распаковывает в путь с кириллицей и пробелами и вызывает `run.bat --check-install` со встроенной Java.

Это проверка Windows-пакета и запуска диагностики; игровой OpenGL, звук и DPI на физических Windows-устройствах этим заданием не проверяются. Статус удалённого workflow нужно смотреть на GitHub; локальные логи не заменяют его результата.

```sh
./gradlew :core:test :lwjgl3:guiSmoke :lwjgl3:installDist -Pproduct=true
java -cp 'lwjgl3/build/install/ctrl-life/lib/*' life.ctrl.desktop.DesktopLauncher --check-install
```

На Windows воспроизведена ошибка загрузчика Java из пути с кириллицей. Проверены варианты пути и DLL; новый лаунчер с закрытой временной папкой для Java, библиотек и JNI-распаковки прошёл диагностику на Windows Server 2025. Короткие DOS-имена не требуются. Полная проверка run.bat выполняется релизным workflow.
