# Roadmap

## Gate 0–1 — текущая 0.1.0

- [x] Java 21, libGDX, LWJGL3, Gradle Wrapper, lock-файлы.
- [x] Сборка, реальный графический запуск в Linux.
- [x] Комната, подъезд, улица; коллизии, камера, двери.
- [x] Оригинальные PNG, анимации ходьбы, кириллица.
- [x] Три NPC с маршрутами, диалоги и история с письмом.
- [x] Меню, создание персонажа, журнал, карманы, карта.
- [x] Сохранение, резервная копия, продолжение, настройки.
- [x] Оригинальные WAV, раздельные уровни звука, уменьшение эффектов.
- [ ] Выполнить ручной чек-лист на Windows и проверить реальный звук.

## Gate 2 — ближайший этап

- [ ] Типизированные предметы и инвентарь с атомарными операциями.
- [ ] Открыть интерьер продуктового и торговлю, тесты списания ровно один раз.
- [ ] Еда, отдых, мягкие потребности, понятные временные затраты.
- [ ] Интерьер прачечной; задача стирки продолжает жить между картами и сейвами.
- [ ] Доступная подработка без ПК и гарантированный выход из бедности.
- [ ] Аренда, защита от повторных списаний после загрузки.
- [ ] Миграция сохранений v1 → v2.

## Gates 3–6 — полноценная вертикальная демоверсия

- [ ] Поиск электроники, мастерская, диагностика, совместимость и ремонт ПК.
- [ ] ByteOS и KeyCode; физический набор последовательностей клавиш.
- [ ] ByteScript lexer/parser/AST/evaluator, раздельные синтаксические и логические ошибки.
- [ ] Работающий предпросмотр, реальные тесты, заказы и однократная оплата.
- [ ] Восемь законченных пространств, основной сюжетный эпизод и 45–90 минут контента.
- [ ] Расписания NPC/магазинов, события и баланс.
- [ ] Windows-релиз, упаковка jpackage на Windows, полный приёмочный чек-лист.

## После демоверсии

Новые районы и карьеры → отношения взрослых и совместный быт → жильё, семья и жизненные главы → собственная компания и долгосрочные истории. Не создавать кнопки для ещё не работающих функций.
