# AutoGDBot Verified v1.0.0-alpha.1

Новая основа использует MIT-код gdsolver: поиск пути → проверка в самой игре → исправление расхождений → обычное воспроизведение найденного пути. Это замена прежнего короткого прогноза AutoGDBot, а не подстройка его параметров.

В Android-профиле два потока поиска. Проверка кандидатов ограничена бюджетом 6 мс на серию обновлений; одно тяжёлое обновление игры может занять больше. Плавность на реальном устройстве не измерена.

Для запуска: GD 2.2081, Geode 5.10.1 или совместимая более новая версия, Android64. Отключи прежний AutoGDBot и GD Solver, установи новый .geode, открой уровень и выбери Solve. Сначала идёт подготовка пути; после подтверждённого игрой прохождения начнётся обычное воспроизведение. Для повторного запуска используй Replay. Кнопки управления доступны на экране.

Путь и карта попыток сохраняются отдельно для точного содержимого уровня, версии движка и Android64. Старые планы не подмешиваются после изменения уровня.

100% всех уровней не обещается. Android-порт gdsolver экспериментальный, а эту сборку ещё нужно проверить внутри Android GD. Platformer не поддерживается. Успех и отсутствие лагов можно оценить только по настоящим прохождениям и замерам времени кадра.

Исходники сохраняют авторство gdsolver. Собственная часть здесь — Android-профиль, изоляция кэша и воспроизводимая сборка с проверкой пакета.
